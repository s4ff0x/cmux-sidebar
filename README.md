# cmux-sidebar

Custom left sidebar for [cmux](https://cmux.com), built on the cmux JS custom-sidebar runtime
(`~/.config/cmux/sidebars/<name>.js`, see the [authoring guide](https://cmux.com/docs/custom-sidebars)).

Planned features (see GitHub issues):

- Nested workspace groups; create workspaces directly inside a group
- Orange indicator on workspaces with a working coding agent (Claude Code, omp)
- Collapsed groups still show running workspaces; only finished ones are hidden
- Per-workspace left border color
- Hotkey toggling a running-only view
